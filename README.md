# HSK 3 Master - ระบบติวและทดสอบภาษาจีน HSK ระดับ 3 🇨🇳🇹🇭
### ออกแบบพิเศษเพื่อช่วยคุณพ่อคุณแม่ในการติวและทดสอบภาษาจีนให้ลูก แม้คุณพ่อคุณแม่จะอ่าน ฟัง หรือเขียนภาษาจีนไม่ได้

---

## 🎯 ตอบโจทย์ปัญหาของคุณพ่ออย่างไร?

1. **คุณพ่อไม่ต้องพูดหรืออ่านภาษาจีนเอง:**
   - ระบบมีเสียงอ่านภาษาจีนสำเนียงมาตรฐาน (Web Speech API) พร้อมปุ่มปรับความเร็วเสียง (ปกติ 1.0x / ช้า 0.8x สำหรับผู้เริ่มฝึก)
2. **คุณพ่อไม่ต้องตรวจคำตอบเอง:**
   - ระบบตรวจข้อสอบอัตโนมัติ 100% พร้อมเฉลยภาษาไทยอย่างละเอียด และคำแปลที่ตรงกับเอกสารทางการ
3. **ติดตามคำศัพท์ที่ลูกตอบผิด (错题本):**
   - คำศัพท์ใดที่ลูกตอบผิด จะถูกบันทึกเข้า "สมุดรวมคำที่ตอบผิด" ทันที พร้อมปุ่มให้ลูก "ทำซ้ำเฉพาะคำที่ตอบผิด" จนกว่าจะตอบถูก
4. **จำลองห้องสอบจริงตามมาตรฐาน HSK 3:**
   - มีระบบจำลองสอบ 25 ข้อ จับเวลา 30 นาที คิดคะแนนเต็ม 300 คะแนน (เกณฑ์ผ่าน 180 คะแนน เหมือนสถาบันขงจื่อ / Hanban)
5. **พิมพ์แบบฝึกหัดกระดาษได้ (Printable Worksheets):**
   - สามารถกดพิมพ์ชุดทดสอบ 10-20 ข้อ บนกระดาษ A4 สวยงาม พร้อมเฉลยสำหรับคุณพ่อไว้ตรวจท้ายชุด

---

## 🚀 วิธีเปิดใช้งานโปรแกรม

### วิธีที่ 1 (ง่ายที่สุด):
- ดับเบิ้ลคลิกไฟล์ **`START_HSK3.bat`**
- ระบบจะเปิดเบราว์เซอร์ให้อัตโนมัติที่ `http://localhost:8080`

### วิธีที่ 2 (ผ่าน Terminal / Command Line):
```bash
python server.py
```
- จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:8080`

### วิธีที่ 3 (เปิดตรงผ่านเบราว์เซอร์):
- ดับเบิ้ลคลิกไฟล์ **`index.html`** เพื่อเปิดใน Google Chrome หรือ Microsoft Edge ได้ทันที

## 📚 ฐานข้อมูลในระบบ (จากไฟล์ Vocabulary_HSK_3.pdf)
- **คำศัพท์ทั้งหมด:** 600 คำ (HSK 1: 150 คำ, HSK 2: 150 คำ, HSK 3: 300 คำ)
- **ประโยคตัวอย่างจริง:** 716 ประโยค พร้อมพินอินและความหมายภาษาไทย
- **รูปแบบแบบทดสอบ:**
  - 🎧 **การฟัง (听力):** ฟังเสียงแล้วเลือกตัวอักษรจีน หรือเลือกความหมายไทย
  - 📖 **การอ่าน (阅读):** จับคู่คำศัพท์, จับคู่พินอิน, และเติมคำลงในช่องว่างของประโยค
  - ✍️ **การเขียน (书写):** เรียงบล็อกคำเป็นประโยค (连词成句) และคัดอักษรจีนตามพินอินบนกระดานดิจิทัล (米字格)

---

## 👨‍👧 โครงสร้างเมนูหลัก
- 🏠 **หน้าแรก (Dashboard):** นับถอยหลังวันสอบ, บัตรสรุปสถิติ, เมนูเลือกแบบทดสอบด่วน
- 🎯 **ทำแบบทดสอบ (Quiz):** หน้าจอทำข้อสอบแบบโต้ตอบ พร้อมระบบตรวจและเฉลยทันที
- 🗂️ **คลังคำศัพท์ (Flashcards):** พลิกการ์ดคำศัพท์ 600 คำ พร้อมเสียงอ่าน และตารางสืบค้น
- 📕 **สมุดข้อที่ตอบผิด (Mistakes):** รวมคำศัพท์ที่ลูกเคยทำผิด พร้อมปุ่มฝึกซ้ำ
- 👨‍🏫 **สถิติสำหรับคุณพ่อ (Parent):** วิเคราะห์จุดอ่อน-จุดแข็งรายทักษะ และสถิติความพร้อม
- 🖨️ **พิมพ์ใบงานกระดาษ (Worksheet):** สร้างและสั่งพิมพ์แบบฝึกหัด A4
